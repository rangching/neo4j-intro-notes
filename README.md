# Neo4j 入門：一步一步做出你的第一張知識圖譜｜學習網頁

線上網址：https://rangching.github.io/neo4j-intro-notes/

6 集 × 約 15 分鐘的 Neo4j 入門課程自學網頁：每集有學習單（前測、術語、練習、後測）、影片與步驟時間軸、筆記、背誦卡、測驗。學習進度只存在自己瀏覽器裡。

純靜態網頁（GitHub Pages），沒有建置步驟：

- `content.js`：課程內容
- `videos.js`：影片連結（由流水線自動回寫）
- `index.html`：版面

本機預覽：`python3 -m http.server 8190`
